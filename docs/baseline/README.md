# Baseline

`finops-baseline.md` is the single append-only record of this engagement's
numbers. It is created in Phase 00 and appended to by every subsequent
phase — never rewritten, never backfilled with rounder numbers after the
fact. If a number changes because a metric turned out to be wrong, the
correction is a new dated entry, not an edit to the old one. That's the
whole point of the file: it has to survive someone asking "are you sure
that's what it said at the time?"

Per-phase raw exports (`0X-*.txt`, Cost Explorer tables, Kubecost JSON,
etc.) also live in this directory, referenced by each phase's `README.md`
"Numbers, before and after" table. A number in a phase README without a
corresponding file here is a number that didn't happen yet.

`finops-baseline.md` itself is generated by `phases/00-engagement-kickoff/`
and is not committed pre-filled — see that phase's runbook.
