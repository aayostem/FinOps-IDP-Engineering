# Coverage Scorecard

Updated every time a phase is written or revised. Score is out of 10,
judged against `docs/walkthrough-map.md`'s segment list for that phase's
series — not a vibe check. See `PRODUCTION-GUIDE.md` §8 for how a score is
assigned: each segment is either represented in the phase's "The work"
section (even condensed), explicitly cut with a reason in the map, or
missing. Missing segments cap the score; explicitly-cut ones don't.

A score must come from actually re-reading the phase's "The work"
section against the map line by line, not from recalling that the
phase "was fixed already." Phase 03 was marked 10/10 once, incorrectly
— two segments turned out to be entirely absent and two more existed
only in a numbers table or carries-forward, never narrated as real
beats. The error wasn't the content being hard to write; it was scoring
from memory of the fix instead of checking the fix.
